# hop

키 하나(기본값 `XF86Tools`)로 작업공간을 전환하는 작은 X11 데몬입니다.

| 입력 | 동작 |
|---|---|
| `Tools` 짧게 누르기 | 창이 열려 있는 다음 작업공간으로 이동 (마지막 다음은 처음). 빈 작업공간은 건너뜀 |
| `Tools` 누른 채 `1`–`9`, `0` | 1–10번 작업공간으로 이동 (비어 있어도 이동, 키패드 숫자 포함) |
| `Tools` 누른 채 다른 키 | 아무 동작 안 함 (그 키도 창에 입력되지 않음) |

`Tools`를 누르고 있는 동안에는 키보드 입력을 hop이 받으므로, 함께 누른 숫자가 포커스된 창에 입력되지 않습니다. 전환은 EWMH `_NET_CURRENT_DESKTOP` 요청으로 창 관리자에 맡기므로 EWMH를 지원하는 창 관리자라면 동작합니다(xfwm4에서 확인).

키보드를 새로 연결하거나 `setxkbmap`·`xmodmap`으로 키맵이 바뀌면 Tools 키를 자동으로 다시 잡습니다.

## 요구 사항

- X11(`libX11` 헤더), C 컴파일러, `pkg-config`
- 작업공간이 여러 개인 창 관리자. xfwm4라면 다음과 같이 늘릴 수 있습니다.

  ```sh
  xfconf-query -c xfwm4 -p /general/workspace_count -s 10
  ```

## 빌드와 설치

```sh
make
make install      # ~/.local/bin/hop 과 XFCE 자동 실행 항목을 설치
```

다시 로그인하지 않고 바로 실행하려면:

```sh
setsid -f ~/.local/bin/hop
```

제거는 `make uninstall`로 합니다(실행 중인 hop도 종료).

다시 설치해도 이미 실행 중인 hop은 옛 버전 그대로입니다. 새 버전을 쓰려면 hop을 종료하고 다시 실행하세요.

자동 실행으로 켜진 hop의 메시지는 따로 저장되지 않습니다. 문제를 확인하려면 hop을 종료한 뒤 터미널에서 `~/.local/bin/hop`을 직접 실행해 출력을 보세요.
